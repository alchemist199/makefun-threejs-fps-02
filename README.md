EMBERLINE is a three.js tactical FPS: bot teammates and enemies, round-based play, a buy-phase weapon economy, and a full HUD. Plain static files, no build step, three.js 0.187.0 vendored in.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
